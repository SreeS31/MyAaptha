    Status and evidence policy

    Completed = all applicable checks are recorded complete. Pending includes not started, blocked and needs verification. A task with no applicable checks is never complete.

    Stage meanings: Coding = source/preparation; Testing = recorded verification; Integration = recorded local workflow/integration. External launch gates use N/A for coding because configuration or approval is not missing application code.

    The baseline uses dated verification records (mostly 6–10 October and earlier). Recent development rows link newly recorded tests and workflow checks; older rows retain their historical evidence. Source existence alone is not fresh test evidence. Owners are proposed teams, not assigned individuals.

    The latest recorded 5,000-user test failed its gates (28 September). Recovery, independent security review, cloud rollout and store distribution remain unverified. If native launch or optional providers are deferred, move the corresponding tasks explicitly; they are not silently counted complete.

    Module placement follows its earliest unfinished subtask. Moving a module changes unfinished task phases only. Marking a phase Done does not mark checks complete.
