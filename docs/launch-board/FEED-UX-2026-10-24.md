# Online Feed: compact stream and actions

24 October 2026. Scope: responsive web Online Feed and the shared Diary post cards. Existing API contracts and native Android build are unchanged.

The feed now displays one centered column, ordered by creation time descending with ID as the tie breaker. Post notification links locate the actual post ID rather than an index in a differently filtered list. Cards have compact SVG like, comment, share and save controls; counts are inline. Comments open on demand and report controls are available from More options. Existing owner edit/delete, story, attachment, audience, saved-post and sharing features remain available.

Online Feed opens with a compact writing bar; expanding and folding preserves the draft. Diary keeps its editor visible. The comment field matches the existing API's 1,000-character limit. Action failures are surfaced, and pending mutations disable repeat controls. Media keeps its proportions within the centered card width.
