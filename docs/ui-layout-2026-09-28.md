# Compact workspace layout — 28 September 2026

The shared web layout now uses a single 60px header offset, a working 220px
sidebar width, and a 12px gap before page content. Tablet and phone layouts keep
navigation outside the content columns and preserve room for the mobile toolbar.
The layout fixes column sizing rather than hiding page overflow.

The diary page has a short heading, only diary-specific navigation, an expandable
story composer, and no empty story gallery. Existing stories wrap into a responsive
grid. The entry editor appears immediately below the story control. Longer help
text is available through the information button. Attachment loading/error states
use a compact status area instead of an indefinitely empty media panel.

The shared Roboto typography, 14px body text, three heading sizes, pastel controls,
keyboard focus styles and larger touch controls are retained. Shared spacing and
navigation changes apply to all web routes, including mobile web; this change does
not rebuild or redesign the native Flutter application.
