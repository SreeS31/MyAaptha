# Compact, collapsed saved-tree defaults

Saved trees start in Compact layout with the You root closed. Clicking You reveals the first level; individual branch controls reveal descendants. Expand all is still available. Reset view closes the saved tree and restores Compact and the original zoom. Switching saved trees starts the newly selected tree closed in Compact as well, regardless of an older saved layout preference.

The shared web and native reviewed-tree canvases default to Compact, with descendant branches closed. Editors still reveal the ancestors of a specifically selected person so Edit person remains useful. Closed saved trees hide their empty canvas instead of occupying a large blank area. Tree data, gender colors, filled branch markers, outlined end markers and the other display formats are preserved. No API or schema changes are required.
