# All saved trees around You

My trees replaces its single-tree dropdown with a circular overview. You is the central node, with a visible connector to every saved tree. Tree names and member counts appear as buttons around concentric rings. Every tree starts closed. Clicking a tree opens its Compact diagram below the overview; trees open and close independently, so several can remain open together. Descendant branches remain collapsed until requested. Edit tree, Edit person, Delete tree, layouts, zoom, gender colors and branch/end markers remain available.

Web and native clients load all pages of the existing owner-scoped tree-card API. Full private tree snapshots are fetched only for opened trees. Closing a tree cancels its UI update, preventing late responses from reopening it. Expanded diagrams label their root with the tree name; the overview has the single central You node. The overview supports scrolling on web and pan/zoom with initial fitting on native for larger collections. No stored tree data or API/schema changes are required.

Validation and release evidence will be recorded after checks complete.
