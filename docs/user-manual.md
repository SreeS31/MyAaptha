# MyAaptha User Manual

## Getting Started

1. **Register** at `/register` with email and password, or use Google/Facebook/Apple sign-in.
2. **Create a Circle** — choose category (Family, Office, etc.) and visibility.
3. **Add members** as person nodes with profile details.
4. **Define relationships** (Father, Spouse, Colleague, etc.).
5. **Explore the tree** — zoom, pan, expand branches, search members.

## Circles

A **Circle** is a relationship tree. You can create unlimited circles for different contexts.

### Circle actions
- **Archive** — hide without deleting
- **Clone** — duplicate structure
- **Merge** — combine duplicate profiles
- **Export** — PDF, CSV, Excel, JSON, printable image
- **Share** — invite others with role (Editor, Viewer, Guest)

## Tree Visualization

- **Colors:** Male (light blue), Female (light pink), Unknown (gray)
- **Borders:** Green (you), Gold (owner), Orange (editor), Gray (viewer), Purple (selected)
- **Layout:** Parents top, children bottom, spouses side-by-side
- Click a node to expand children (lazy loading for large trees)

## Relationships

The system automatically computes kinship:
- Example path: You → Father → Brother → Son = **Cousin**

Use **Kinship lookup** on any two members to see the relationship label and path.

## Search

- Global search across all your circles
- Filter by name, company, city, tags, relationship type
- Voice search (mobile) and AI natural language search (premium)

## Calendar & Reminders

- Birthdays and anniversaries auto-populated from node DOB
- Custom events and community gatherings
- RSVP tracking for reunions

## Communication

Send messages via SMS, WhatsApp, Email, or in-app push to filtered groups:
- Entire tree, branch, siblings, birthday-today, inactive members, etc.

## Mobile App

- **Offline mode** — view cached trees without network
- **Biometric login** — fingerprint/face unlock
- **QR sharing** — share profile or circle via QR code
- **Contact import** — Google Contacts, vCard, CSV

## Privacy

Control visibility per circle: Private, Friends, Relatives, Community, Public, Hidden.

Fine-grained ACL lets you grant edit access to a single branch without exposing the full tree.
